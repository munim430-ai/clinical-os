## 2024-05-18 - Adding Accessibility to Interactive Components
**Learning:** In a React Native codebase where standard HTML buttons and inputs are not available, custom interactive components like `TouchableOpacity` or `Pressable` require explicit accessibility configuration (e.g., `accessibilityRole`, `accessibilityLabel`, `accessibilityState`, and `hitSlop`).
**Action:** When auditing or implementing interactive elements that act as buttons or inputs in React Native, ensure these accessibility properties are consistently applied for robust screen reader support and better touch targets.
