## 2024-11-20 - Adding Accessibility to Icon-Only Buttons
**Learning:** Icon-only interactive elements, such as theme toggles, often lack explicit semantic meaning for screen readers. Using `accessibilityRole="button"` and `accessibilityLabel` is critical in React Native. Additionally, relying solely on standard touch target sizes for small icons is an accessibility antipattern; utilizing `hitSlop` enhances usability significantly by expanding the interactive area without changing visual layouts. Using `accessibilityState` provides interactive feedback.
**Action:** When implementing custom icon-only components (e.g., using `Pressable` or `TouchableOpacity`), enforce the inclusion of `accessibilityRole`, a descriptive `accessibilityLabel`, state indication through `accessibilityState` (where applicable), and an adequate `hitSlop` to ensure robust accessibility and usability across devices.
