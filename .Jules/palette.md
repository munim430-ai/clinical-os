## 2025-02-23 - [AI Orb Accessibility Improvement]
**Learning:** React Native's `Pressable` components don't natively expose custom properties to screen readers. For purely visual/interactive components like the `AIOrbButton` that use icons + text but aren't standard buttons, explicit `accessibilityRole="button"`, a contextual `accessibilityLabel`, and an `accessibilityState={{ expanded: active }}` must be set. Additionally, using an explicit object (`{ top: 15, bottom: 15, left: 15, right: 15 }`) for `hitSlop` is safer and more consistent than a single scalar value.
**Action:** When adding or modifying interactive UI components like FABs, AI orbs, or custom toggle buttons, always define `accessibilityRole`, provide an `accessibilityLabel`, bind the state (`expanded` or `selected`), and ensure adequate `hitSlop` using the full object format.
